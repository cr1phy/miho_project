# Logic Lab client

Минимальное настольное приложение на Rust и egui/eframe. Выражение вычисляется
в C++-библиотеке `miho_project` через C ABI из `core/miho_c.h`.

```sh
cd client
cargo run
```

Нужны Rust 1.95+, CMake, компилятор C/C++ и графическая сессия Linux (X11 или Wayland).
`build.rs` автоматически собирает соседний `../core` и статически подключает
библиотеку. Копировать `.so` или задавать `LD_LIBRARY_PATH` не нужно.
Для другого расположения исходников можно задать `MIHO_CORE_DIR`.

Введите выражение, например `~A | (B & 1)`, и значения `A=1, B=0`.
Результат обновляется при редактировании, по Enter и кнопке «Вычислить».
Для выражения `~0 & 1` значения переменных можно оставить пустыми.
Ошибки разбора и отсутствующие значения показываются вместо результата.
Позиции в сообщениях ядра считаются с нуля.

```sh
cargo test
```

Тесты вызывают настоящую C++-библиотеку через FFI, проверяют операции,
ошибки, значения переменных и параллельные вызовы. C++ исключения перехватываются
на границе C ABI; память входных и выходных буферов принадлежит вызывающей стороне.
Визуальная часть содержит стилизованный рисунок бюста в бикини, нарисованный egui.
